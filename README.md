# Portfolio Clone

This is a Next.js + Tailwind portfolio template (App Router) cloned for demonstration.

## Run locally

1. Install deps:
   ```
   npm install
   ```
2. Run dev:
   ```
   npm run dev
   ```

3. Build:
   ```
   npm run build
   ```

## Deploy
Deploy to Vercel (recommended) by connecting your GitHub repo. Next.js App Router works out-of-the-box with Vercel.
